## 🧠 專案簡介（Overview）

這是一個以「日本旅遊」為主題的 **靜態單頁式網站**，  
主要練習 **HTML、SCSS、RWD 版面設計與動態視覺呈現**。

網站包含旅遊介紹、主題圖片展示、地圖導覽、以及自動切換背景圖的簡易動畫。  
整體風格以「乾淨、旅遊海報風」為設計方向，著重於排版美感與內容視覺一致性。

---

## ⚙️ 使用技術（Tech Stack）

- **HTML5**：語意化標籤結構
- **SCSS / CSS3**：模組化樣式與 RWD 響應設計
- **JavaScript (Vanilla)**：背景圖片自動輪播
- **Font Awesome**：導覽列圖示
- **Google Maps Embed API**：顯示日本地理位置
- **GitHub Pages**：靜態網站部署

---

## 🌟 功能特色（Features）

- 🔹 **背景自動切換**：使用 `setInterval()` 每 3 秒輪播日本風景背景圖
- 🔹 **主題圓形圖片展示**：四大主題（北海道雪景、壽司、美食、清水寺）
- 🔹 **固定背景圖層**：全螢幕 `fixed` 背景圖，營造深度感
- 🔹 **內嵌 Google 地圖**：介紹日本地理與氣候位置
- 🔹 **響應式設計**：於 1350px/430px(mobile) 以下自動調整導覽列與版面
